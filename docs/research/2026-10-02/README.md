are kept as evidence: sources, measurements, file:line maps and the options
that were weighed. Line numbers point at commit `fc74e69` and drift as the code

accounts and cloud AI. The five here are about things MockMyApp still does, so
they stay useful; where one talks about purchases, sign-in, Firebase or cloud
